## 🚀 About Me

I'm a third-year Computer Engineering student at **SKN Sinhgad Institute of Technology & Science** (SPPU, Pune), building at the intersection of **AI agents, automation, and cloud security**. When I'm not in class, I'm usually shipping something for a hackathon, breaking my own code to understand it better, or chasing the next certification on my way to becoming a cloud security engineer.
